# CoreStory

Public release home for CoreStory command-line, MCP, and web distribution artifacts.

Source code remains private.
This repository carries versioned release artifacts, checksums, signatures, software bills of materials, and the install script.

## Install

A release has not been published yet.
When the first supported release is available, this repository will document verified macOS, Linux, and Windows installation paths.

## Verify a release

Every release will include SHA256 checksums, signatures, and an SBOM.
Verify the checksum and signature before installing an artifact.
